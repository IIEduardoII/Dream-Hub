# Dream-Hub
O Dream Hub é um sistema pessoal autônomo que roda 24/7 em um Android como servidor privado via Tailscale. Centraliza a rotina em quatro pilares: Tarefas (Kanban e foco), Tempo (Pomodoro customizável), Finanças (fluxo de caixa e controle de gastos) e Segundo Cérebro para ideias e anotações.
