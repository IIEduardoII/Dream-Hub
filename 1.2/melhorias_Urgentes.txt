================================================================================
GUIA DE CORREÇÃO: QUEBRA DE LINHA E LAYOUT DOS CARDS NO KANBAN
================================================================================

1. DIAGNÓSTICO DO ERRO
--------------------------------------------------------------------------------
No layout atual, o título ("Estudo IA", "Academia") e as badges ("🔥 2 dias", 
"DIÁRIA", "HIGH") estão compartilhando a mesma linha em um contêiner flexível 
(display: flex; flex-direction: row;).

Como as colunas do Kanban têm largura fixa e as badges possuem largura rígida, 
o contêiner do título é comprimido até restar espaço apenas para poucas letras, 
provocando a quebra silábica indesejada ("Estu / do / IA").


2. SOLUÇÃO RECOMENDADA (ABORDAGEM EM COLUNA: 100% DE LARGURA PARA O TÍTULO)
--------------------------------------------------------------------------------
A melhor prática para cards verticais de Kanban é separar o cabeçalho em duas 
camadas: as etiquetas de identificação no topo e o título logo abaixo, livre 
para ocupar toda a extensão horizontal do card.

--- [OPÇÃO 1A: IMPLEMENTAÇÃO EM TAILWIND CSS] ---

Substitua o cabeçalho do card por:

<div class="flex flex-col gap-1.5 mb-2">
  <!-- Linha Superior: Badges agrupadas com quebra automática se faltar espaço -->
  <div class="flex flex-wrap items-center gap-1.5">
    <!-- Streak -->
    <span class="inline-flex items-center px-2 py-0.5 rounded-full text-xs font-semibold bg-amber-950/60 text-amber-400 border border-amber-800/50">
      🔥 2 dias
    </span>
    <!-- Recorrência -->
    <span class="inline-flex items-center px-2 py-0.5 rounded-full text-xs font-semibold bg-emerald-950/60 text-emerald-400 border border-emerald-800/50">
      🔄 DIÁRIA
    </span>
    <!-- Prioridade -->
    <span class="inline-flex items-center px-2 py-0.5 rounded-full text-xs font-semibold bg-yellow-950/60 text-yellow-400 border border-yellow-800/50">
      HIGH
    </span>
  </div>

  <!-- Linha Inferior: Título com largura total -->
  <h3 class="text-base font-semibold text-white leading-tight break-words">
    Estudo IA
  </h3>
</div>


--- [OPÇÃO 1B: IMPLEMENTAÇÃO EM CSS TRADICIONAL] ---

Estrutura HTML:
<div class="card-header">
  <div class="card-badges">
    <span class="badge badge-streak">🔥 2 dias</span>
    <span class="badge badge-recurrence">🔄 DIÁRIA</span>
    <span class="badge badge-priority">HIGH</span>
  </div>
  <h3 class="card-title">Estudo IA</h3>
</div>

Folha de Estilos (CSS):
.card-header {
  display: flex;
  flex-direction: column;
  gap: 6px;
  margin-bottom: 8px;
}

.card-badges {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  gap: 6px;
}

.card-title {
  font-size: 1rem;
  font-weight: 600;
  color: #ffffff;
  margin: 0;
  line-height: 1.3;
  width: 100%;
  word-break: normal;
  overflow-wrap: break-word;
}


3. SOLUÇÃO ALTERNATIVA (MANTER TÍTULO E BADGES LADO A LADO)
--------------------------------------------------------------------------------
Caso queira manter os elementos na mesma linha, você deve permitir que as badges 
saltem para a linha de baixo caso a coluna aperte, sem esmagar o título.

--- [CSS PARA LADO A LADO FLEXÍVEL] ---

.card-header-row {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  justify-content: space-between;
  gap: 8px;
  margin-bottom: 8px;
}

.card-header-row .card-title {
  flex: 1 1 140px;      /* Garante no mínimo 140px antes de empurrar o resto */
  font-size: 1rem;
  font-weight: 600;
  color: #fff;
  word-break: normal;
  white-space: normal;
}

.card-header-row .card-badges {
  display: flex;
  flex-wrap: wrap;
  gap: 4px;
  flex-shrink: 0;
}


4. PONTOS DE ATENÇÃO E REGRAS A REMOVER
--------------------------------------------------------------------------------
1. Verifique se no título não existe a classe ou estilo:
   `word-break: break-all;`
   Essa propriedade obriga o navegador a cortar a palavra no meio de qualquer 
   sílaba assim que encosta na margem. Substitua por:
   `word-break: normal;` ou `word-break: keep-all;` com `overflow-wrap: break-word;`.

2. Certifique-se de que o contêiner das badges tenha `flex-shrink: 0;` para não 
   distorcer o tamanho dos botões.
